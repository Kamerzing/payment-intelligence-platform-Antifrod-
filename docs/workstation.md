## Ресурсные ориентиры

| Режим | RAM | Свободный диск |
| --- | --- | --- |
| Облегчённая разработка | 8 ГБ, с ограничениями и последовательным запуском | 40–50 ГБ |
| Полный стенд одновременно | От 16 ГБ, предпочтительно 32 ГБ | 60–80 ГБ |

Значения — предварительная инженерная оценка, не измеренное потребление. Желателен SSD. 4 ГБ VRAM не гарантируют размещение модели: кроме весов нужны контекст и служебная память. Начальная модель — `qwen3:4b-instruct`, Q4, один запрос одновременно; фактическое использование GPU, память и задержки измеряются отдельным этапом.

На 8 ГБ запускайте один backend и БД. Ядро, E2E, полную сборку и реальную модель подключайте по необходимости; не выполняйте их одновременно. Для тяжёлых проверок можно закрыть IDE. Размер heap не равен полному потреблению процесса.

В проекте ограничены Gradle heap 512 МБ, workers 2, backend heap 384 МБ в подготовленных конфигурациях, test heap 384 МБ и один fork. PostgreSQL-контейнер ограничен 256 МБ; пул приложения — пять соединений. Глобальные настройки Java, WSL и IDE автоматически не меняются.

## Необходимые программы

- IntelliJ IDEA: открыть Gradle-проект; SDK и Gradle JVM — 21. [Официальные требования](https://www.jetbrains.com/help/idea/installation-guide.html).
- JDK 21: компиляция и запуск. Runtime, встроенный в IDE, не заменяет SDK проекта.
- Node.js 24 и npm: React/Vite, typecheck, frontend-тесты и сборка панели.
- Git: локальная история и будущий удалённый репозиторий.
- Docker Desktop, Compose и WSL 2 с Linux containers: PostgreSQL и Testcontainers. Нужны поддерживаемая версия Windows и аппаратная виртуализация. [Требования Docker](https://docs.docker.com/desktop/setup/install/windows-install/).
- Браузер для UI; Chromium для Playwright устанавливается отдельно командой из README.
- Ollama и совместимый драйвер NVIDIA: для включаемого отдельно ИИ. Скрипт проекта запускает отдельный runtime на `http://127.0.0.1:11435` с отключённым облаком; внешний fallback не предусмотрен. Настройка и лимиты: [этапы 7–8](stages-7-8.md). [Ollama Windows](https://docs.ollama.com/windows), [поддержка GPU](https://docs.ollama.com/gpu).

Gradle приходит через Wrapper, PostgreSQL — через Docker. Для backend-тестов Python, отдельная установка PostgreSQL и модель не требуются. Настоящая генерация требует отдельной загрузки Qwen3; её параметры закреплены в [ai-model-lock.json](ai-model-lock.json).

## Диагностика запуска

`java -version` должен показывать 21 для текущей сессии; `node --version` — 24. `docker info` должен возвращать данные сервера, а не только версию CLI. Затем `docker compose up -d --wait postgres`, запуск backend и HTTP readiness должны завершаться успешно.

Не меняйте рабочие Docker volumes и существующие пароли ядра, чтобы исправить новый проект. Ошибки доступа к Docker и отсутствие Engine устраняются отдельно от приложения.
